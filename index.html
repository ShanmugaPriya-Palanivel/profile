RAG-Based Local Document Q&A System

Personal Project  ·  Python · LangChain · Ollama · ChromaDB

Built an offline document chatbot using a local LLM — zero internet, zero paid APIs, 100 % private. Implemented a full RAG pipeline with hybrid vector + BM25 search and source-linked answers.

Combined ChromaDB vector embeddings with BM25 keyword search for hybrid retrieval, improving accuracy for both semantic queries and exact keyword lookups. Every response is linked back to its source document chunk so users can verify answers. All processing stays local — no data ever leaves the machine.

2025

Offline UPI Transaction System

Personal Project  ·  Java · Spring Boot · Spring Security · RSA-2048

Designed a secure offline payment system using Store-and-Forward relay architecture, RSA-2048 digital signatures, nonce-based replay protection and TTL validation.

Built RESTful APIs for payment processing, account validation and ledger settlement with Spring Boot. Private keys reside on the sender's device; transactions are verified via public-key cryptography. Nonce-based replay protection eliminates double-spending and TTL auto-expires stale requests.
